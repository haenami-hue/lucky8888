# 번호 추천 로직

추천은 **질문 2개(각 3지선다) + 생년월일(선택) + 추첨일 일진**을 번호별 가중치로 바꾼 뒤,
가중 무작위 추출과 조합 필터로 5게임을 만든다. 구현: `src/features/recommend/engine.ts`.

## 1. 오행 수리 (하도 河圖)

번호의 끝자리로 오행을 정한다: 1·6 水, 2·7 火, 3·8 木, 4·9 金, 5·0 土.
상생: 木→火→土→金→水→木 / 상극: 木剋土, 土剋水, 水剋火, 火剋金, 金剋木.

## 2. 가중치

| 입력 | 효과 |
|---|---|
| 질문 1 "요즘 마음" | 🔥 바꾸고 싶다 → 최근 50회 자주 나온 번호 + 火 / 🌿 흐름을 타고 싶다 → 균형 필터 강화 + 土 / 🌊 때를 기다린다 → 오래 안 나온 번호 + 水 |
| 질문 2 "음양" | ☀️ 양(홀수) 4개 / ☯️ 조화 3개 / 🌙 음(짝수) 위주 홀수 2개 |
| 생년월일 → 일간(日干) | 나를 생해주는 오행(인성) ×1.5, 나와 같은 오행(비견) ×1.25, 나를 극하는 오행 ×0.75 |
| 추첨일 일진 → 일간 | 그날의 오행 ×1.2 |

## 3. 필터

- 연속 번호 3개 이상 금지, 합계 80~200 (🌿는 100~175, 저·고 번호 각 2~4개)
- 질문 2 의 홀수 개수를 정확히 맞춘다
- 5게임은 서로 중복되지 않는다

## 4. 간지 계산

- 일주: 율리우스일(JDN) 기준 `(JDN + 49) mod 60` 이 甲子=0 인 60갑자 순번. (2000-01-01 = 戊午일)
- 연주: 입춘(2월 4일로 근사) 이전 출생은 전년도로 본다. `(연도 - 4) mod 60`.
- 시주·월주는 쓰지 않는다 (입력 부담을 줄이기 위함).

## 5. 사주 대상

생년월일 단계에서 대상을 고른다: 🙋 나(기기에 저장) / 💝 다른 사람(이름·별명 + 생일, 저장 안 함) / 🏛️ 부자·위인 프리셋(`src/features/recommend/figures.ts`, 부자 4명 + 위인 4명).
프리셋은 작고한 인물만 넣고(한국인 우선), 일진 계산이 그레고리력 기준이므로 1582년 이전 출생자는 넣지 않는다.
대상 이름은 풀이 문구의 "당신" 자리에 들어간다.
